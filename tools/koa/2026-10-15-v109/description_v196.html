Disclosure (October 1, 2026). Published versions 1.4.0, 1.9.0, 1.9.1, 1.9.2 and 1.9.3 of this record identify the 64 Kahikinui installations by strings built from their plot longitude and latitude, in the Install and ID columns of AK_TREE.csv, AK_PLT.csv and AK_PLT_GEO.csv. Version 1.9.5 and later replace them with KFRP-nn pseudonyms and carry no coordinate in any field. Please work from version 1.9.5 or later.

Data, code and deployed constants for Weiskittel, A.R., Sprecher, I., Gottesman, A. and Rice, B., "Development of individual-tree static and dynamic equations for Acacia koa A. Gray in Hawaii for use in a growth and yield model" (submitted to Forest Ecosystems). The record holds the assembled tree-level dataset (AK_TREE.csv, AK_PLT.csv, AK_PLT_GEO.csv), the crown subset (AK_HCB.csv), the survival table (AK_SURV.csv), the plot-level origin and thinning table, the Biomass Yield Index raster (BYI_all.tif, index units), the Python projection simulator (koa_projector.py, koa_equations.py, koa_params.py, threestage.py) and its R carrier (HiGy.R), the deployed constants (v103_constants.json), the number registry behind every reported value (numbers_v103.json), the scripts that produced every table and figure (v103_rebuild_20260930.zip, engine_v103.zip), the manuscript supplement s105 (koa_supplemental.docx, md5 a11cf9ca2bc0941471ffae80d8deae7d), a data dictionary, a file map and SHA-256 checksums.

Version 1.9.6. Removes the reproducibility companion document koa_deposit_companion_v82.docx, which describes equations and calibrations of the September 2026 model generation superseded by the v103 rebuild, replaces the supplement with s105, which accompanies manuscript v109 and rewords revision-history language, states the record retention rules for duplicated and status-conflict visits (Section S1.3) and corrects the description of BYI skill in Section S2.2, and shortens this description, whose version history now lives in DEPOSIT_CHANGELOG.md. No data value, constant or script changed from 1.9.5.

Known limitations, listed in full in README.md: HiGy.R and the FVS-HI variant built on it have differed from the Python simulator in crown recession, in the stand basal area of the height increment density term and in the survival structure, so FVS-HI projections should be checked against koa_projector.py; the DBH.max column of AK_TREE.csv is the plot-year maximum as first assembled and is not the predictor of Eq. 2 (see README.md); the deposit holds no plot coordinates, and true Forest Inventory and Analysis plot coordinates are not released.
